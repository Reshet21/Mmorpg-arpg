# АРКЕОН · G2 · authoritative server

Настоящий многопользовательский сервер для «Мира Завета». **Ноль npm-зависимостей**: HTTP и WebSocket (RFC 6455) реализованы на стандартной библиотеке Node, мир переиспользует `mobile/js/data.js` и `mobile/js/world.js` через `vm` — сервер и клиент живут на одном каноне.

| Параметр | Значение |
|---|---|
| Тик симуляции | 30 Гц ( authoritative ) |
| Снапшоты | 20 Гц, дельта, AOI 40 тайлов / 120 м |
| Игроков | до 200 на процесс, группа до 5 |
| Зоны | 4 общих мира с мобами, элитами, боссами, респавном и Волнами Разлома |
| Античит | валидация скорости/коллизий, серверные кулдауны, `seq` против реплея |
| Лут | владелец на 30 с, идемпотентные `uid` дропов |
| Чат | `local` / `global` / `trade` / `party` |

## Запуск за 10 секунд

```bash
node server/server.js          # по умолчанию 0.0.0.0:8080
PORT=9000 node server/server.js
```

Откройте **http://localhost:8080/** на компьютере. На телефоне в той же Wi-Fi — **http://\<IP-адрес-компьютера\>:8080/**. Клиент сам определит свой origin и подключится к `ws://\<тот же хост\>/ws` — **никаких настроек в игре вводить не нужно**, если открывать именно с сервера, а не с GitHub Pages.

Проверка: `curl http://localhost:8080/health` вернёт JSON с числом игроков, мобов и зон.

> Важно: когда игру открывают с `https://reshet21.github.io/...`, браузер запрещает незащищённые `ws://`. Для Pages нужен сервер за TLS-прокси, и его адрес `wss://…/ws` вводится в стартовом окне или в панели «Группа → Подключение». Без адреса игра честно работает в офлайн-мире с союзниками-призраками.

## Бесплатный облачный деплой

Любой бесплатный хост с Node 18+ и исходящим TLS (Render, Railway, Koyeb, Fly.io, Replit):

1. Создайте сервис из этого репозитория, **Build Command** пустой, **Start Command**: `node server/server.js`.
2. Переменные окружения: `PORT` (обычно назначает хост), `HOST=0.0.0.0`.
3. Хост выдаёт `https://<имя>.onrender.com` — WebSocket будет доступен как `wss://<имя>.onrender.com/ws`.
4. В игре на GitHub Pages: стартовое окно → поле `wss://…/ws` → «Подключиться к серверу», либо панель «Группа».
5. Адрес сохраняется в `localStorage` (`arkeon_server`), повторно вводить не нужно. Поддерживается `?server=wss://…/ws` в URL.

Docker-вариант:

```bash
docker build -f server/Dockerfile -t arkeon-g2 .
docker run -p 8080:8080 arkeon-g2
```

## Протокол

Клиент → сервер:

| `t` | Поля | Назначение |
|---|---|---|
| `hello` | `name, classId, level, zone, x, y` | регистрация, ответ `welcome` |
| `input` | `seq, x, y, hp, level, zone, gearRarity` | предсказанная позиция, 20 Гц |
| `cast` | `name, coeff, tx, ty, range` | авторитетное применение урона |
| `chat` | `ch, text` | сообщение |
| `party` | `act: invite/accept/leave, target, from` | группа |
| `ping` | `ts` | измерение RTT |

Сервер → клиент: `welcome`, `snap` (`players`, `mobs`, `events`, `tick`), `chat`, `party`, `event`, `correction` (античит), `pong`.

## Тест

```bash
node tools/smoke_net.js
```

Поднимает сервер на свободном порту, подключает трёх настоящих WebSocket-клиентов, проверяет `welcome`, видимость всех игроков в снапшоте, движение, чат, авторитетный урон и `/health`, затем гасит процесс.

Связанные документы: `docs/08-server.md`, `docs/09-client.md`, `docs/11-roadmap.md`, `docs/16-mobile.md`. Хартия P3: сервер не имеет платежей и силовых SKU.
