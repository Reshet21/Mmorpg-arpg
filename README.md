# АРКЕОН: Пепел Завета / ARKEON: Ashes of the Covenant

> Изометрическая MMORPG-ARPG нового поколения для Android, iOS и ПК.
> *«Мир не погиб. Он перестал держать слово.»*

Этот репозиторий — **производственная дизайн-библия** проекта (Phase 0 / Discovery) **и исполняемый мобильный вертикальный срез G1**: 16 документов, machine-readable канон, исполняемые симуляторы, SQL-схема, интерактивный хаб и играбельный PWA-прототип боя для телефона. Документы написаны как реальный коммерческий продукт уровня Diablo Immortal / Lost Ark / Albion Online с расчётом на 10M+ MAU, без упрощений и без Pay-To-Win.

## Быстрый старт

```bash
# Интерактивный хаб дизайн-библии (навигация, слои карты, классы, графики, поиск)
python3 -m http.server 8000 --bind 0.0.0.0
# откройте http://localhost:8000/  (в Arena — живой preview на порту 8000)

# Мобильная версия для телефона: тот же сервер, путь /mobile/
# откройте http://localhost:8000/mobile/  (в Arena — preview с /mobile/ на конце)
node --check mobile/js/game.js
node tools/smoke_mobile.js         # headless-бой: 43 проверки логики
python3 tools/gen_mobile_icons.py  # воспроизводимая сборка PNG-иконок

# Пересборка всех моделей и артефактов (только stdlib Python 3.11+)
python3 tools/gen_docs.py          # таблицы классов в docs/05 + схема ролей
python3 tools/economy_sim.py       # 30 дней экономики + CSV + SVG
python3 tools/combat_model.py      # DPS/TTK 6 классов + CSV + SVG
python3 tools/financial_model.py   # бюджет $224.68M + сценарии + SVG
python3 tools/verify_canon.py --strict   # 121 проверка согласованности (CI-гейт)
```

## Публикация: бесплатный облачный хостинг

Игра полностью статическая (Canvas 2D + WebAudio, без сборки и бэкенда), поэтому разворачивается на **GitHub Pages** бесплатно и по HTTPS — это обязательное условие для service worker и установки PWA на телефон.

| Что | Адрес |
|---|---|
| **Игра** | <https://reshet21.github.io/Mmorpg-arpg/mobile/> |
| Хаб дизайн-библии | <https://reshet21.github.io/Mmorpg-arpg/> |

**Однократное включение** (делает владелец репозитория в браузере, без паролей и токенов): откройте <https://github.com/Reshet21/Mmorpg-arpg/settings/pages> → **Source: Deploy from a branch** → ветка `arena/bfc40927-mmorpg-arpg` → папка `/(root)` → **Save**. Через 1–2 минуты ссылки выше начинают работать; `.nojekyll` уже лежит в корне, поэтому Jekyll не тронет PWA-ассеты. Каждый `push` в ветку автоматически обновляет сайт.

Альтернатива — источник «GitHub Actions» и ручной запуск [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml). Токены интеграций (GitHub App), включая выданные песочнице Arena и `GITHUB_TOKEN` в Actions, не могут создать Pages site через REST API — GitHub отвечает `403 Resource not accessible by integration`. Поэтому первичное включение страницы — единственный шаг, который требует человека; весь контент, манифест, иконки и офлайн-кэш уже закоммичены и проверены.

## Мобильная версия · G1 «Рубеж»

[`mobile/index.html`](mobile/index.html) открывается прямо в телефонном браузере и устанавливается как PWA. Это **не упрощённая игра, а первый исполняемый этап**: студия изолировала главный риск мобильного ARPG — читается ли вес удара и телеграф на стекле телефона.

- Сенсорный джойстик, свайп-додж (0.30 с i-frames, 2 заряда / 5.5 с), 6 навыков, ультимейт, pinch-зум 0.65–1.7 и поворот изометрии на 90°.
- Воин и Маг против Стража Рубежа: 4 фазы, шкала стойкости и BREAK, 4 формы телеграфов, адды, энрейдж, 7 реакций канона, экран «Мир помнит».
- 30 Гц симуляция / до 60 Гц рендер, коэффициенты навыков из `data/classes.json`, `FALLBACK` для полного офлайна, HUD ≤ 14 % экрана, цели ≥ 44 dp, настройки доступности.
- Ноль внешних CDN, ноль сборки, ноль платежей и силовых SKU. Подробности: [`mobile/README.md`](mobile/README.md) и [`docs/16-mobile.md`](docs/16-mobile.md).

## Ключевые решения

- **Движок:** Unreal Engine 5.6 (Nanite/Lumen на ПК, 4 профиля масштабируемости на мобильных), изометрическая камера с зумом и поворотом.
- **Сеть:** авторитетный сервер 30 Гц, QUIC + Protobuf, AOI 120 м, 4 000 CCU на реалм × 12 реалмов × 4 региона.
- **Бой:** 6 классов × 3 специализации, додж с i-frames, комбо, крит, 7 стихий и 7 реакций, питомцы и призывы, боссы с 4 фазами.
- **Экономика:** 92% предметов создаются игроками, двойная запись в ledger, контроллер инфляции, 4 зоны закона, BURN части лута.
- **Монетизация:** только косметика и боевой пропуск; Кристаллы Зари **не конвертируются и не передаются**; хартия из 10 обязательств проверяется линтером.
- **Масштаб:** 54 месяца, пик 252 FTE, $224.68M, глобальный запуск 2031-Q2, 5 сезонов в год.
- **Телефон вперёд:** G1 доставляет играбельный срез боя до переноса на UE 5.6; контракты ввода, камеры и телеграфов фиксируются заранее, чтобы 3D-клиент не переучивался.

## Проверка целостности

`tools/verify_canon.py` проверяет 121 условие: 16 документов, веса дропа, таблицу заточки, 6/18/48/144 по классам, биомы, отсутствие конвертера DC→Silver в SQL, совпадение бюджета с каноном, сгенерированные артефакты, а также PWA-манифест, иконки, офлайн-кэш, привязку боя к канону и отсутствие внешних зависимостей в мобильном срезе. Используется как CI-гейт перед мержем в дизайн-библию.
