# АРКЕОН: Пепел Завета / ARKEON: Ashes of the Covenant

> Изометрическая MMORPG-ARPG нового поколения для Android, iOS и ПК.
> *«Мир не погиб. Он перестал держать слово.»*

Этот репозиторий — **производственная дизайн-библия** проекта (Phase 0 / Discovery) **и исполняемый мобильный вертикальный срез G1**: 16 документов, machine-readable канон, исполняемые симуляторы, SQL-схема, интерактивный хаб и играбельный PWA-прототип боя для телефона. Документы написаны как реальный коммерческий продукт уровня Diablo Immortal / Lost Ark / Albion Online с расчётом на 10M+ MAU, без упрощений и без Pay-To-Win.

## Быстрый старт

```bash
# Интерактивный хаб дизайн-библии (навигация, слои карты, классы, графики, поиск)
python3 -m http.server 8000 --bind 0.0.0.0
# откройте http://localhost:8000/  (в Arena — живой preview на порту 8000)

# Мобильная версия для телефона: тот же сервер, путь /mobile/
# откройте http://localhost:8000/mobile/  (в Arena — preview с /mobile/ на конце)
node --check mobile/js/game.js
node tools/smoke_mobile.js         # G1: 43 проверки логики арены
node tools/smoke_g2.js             # G2: 151 проверка мира, графики, гринда, квестов, сети
node tools/smoke_net.js            # 15 проверок настоящего WebSocket-онлайна
node server/server.js              # поднять авторитетный мультиплеер на :8080
python3 tools/gen_mobile_icons.py  # воспроизводимая сборка PNG-иконок

# Пересборка всех моделей и артефактов (только stdlib Python 3.11+)
python3 tools/gen_docs.py          # таблицы классов в docs/05 + схема ролей
python3 tools/economy_sim.py       # 30 дней экономики + CSV + SVG
python3 tools/combat_model.py      # DPS/TTK 6 классов + CSV + SVG
python3 tools/financial_model.py   # бюджет $224.68M + сценарии + SVG
python3 tools/verify_canon.py --strict   # 251 проверка согласованности (CI-гейт)
```

## Публикация: бесплатный облачный хостинг

Игра полностью статическая (Canvas 2D + WebAudio, без сборки и бэкенда), поэтому разворачивается на **GitHub Pages** бесплатно и по HTTPS — это обязательное условие для service worker и установки PWA на телефон.

**Сайт уже включён и собран.** Источник: ветка `arena/bfc40927-mmorpg-arpg`, папка `/(root)`; `.nojekyll` отключает Jekyll. Каждый `push` в ветку пересобирает сайт за 1–2 минуты, статус можно проверить через `gh api repos/Reshet21/Mmorpg-arpg/pages/builds/latest`.

Проверено внешним запросом: `mobile/index.html`, `css/style.css`, `css/g2.css`, `js/game.js`, `js/audio.js`, `js/market.js`, `manifest.webmanifest`, `sw.js`, `data/classes.json` и иконки отдаются с публичного хоста; Pages API возвращает `status: built`.

> ⚠️ **Внутреннее превью Arena — не публичная ссылка.** Адрес вида `https://<порт>-<sandbox>.e2b.app/mobile/` доступен только во вкладке Preview интерфейса Arena: E2B требует заголовок `e2b-traffic-access-token` и извне отвечает `403 Forbidden · Missing traffic access token`. Для телефона используйте адреса из таблицы выше. Локальный `python3 -m http.server 8000` нужен только для разработки.

Первичное включение Pages сделано владельцем репозитория в <https://github.com/Reshet21/Mmorpg-arpg/settings/pages>: автоматически это сделать нельзя, GitHub отвечает `403 Resource not accessible by integration` токенам GitHub App (проверено и через REST `POST /repos/.../pages`, и через `actions/configure-pages`). [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) оставлен как ручная альтернатива на случай источника «GitHub Actions».

## Мобильная версия · G1 «Рубеж»

[`mobile/index.html`](mobile/index.html) открывается прямо в телефонном браузере и устанавливается как PWA. Это **не упрощённая игра, а первый исполняемый этап**: студия изолировала главный риск мобильного ARPG — читается ли вес удара и телеграф на стекле телефона.

- Сенсорный джойстик, свайп-додж (0.30 с i-frames, 2 заряда / 5.5 с), 6 навыков, ультимейт, pinch-зум 0.65–1.7 и поворот изометрии на 90°.
- Воин и Маг против Стража Рубежа: 4 фазы, шкала стойкости и BREAK, 4 формы телеграфов, адды, энрейдж, 7 реакций канона, экран «Мир помнит».
- 30 Гц симуляция / до 60 Гц рендер, коэффициенты навыков из `data/classes.json`, `FALLBACK` для полного офлайна, HUD ≤ 14 % экрана, цели ≥ 44 dp, настройки доступности.
- Ноль внешних CDN, ноль сборки, ноль платежей и силовых SKU. Подробности: [`mobile/README.md`](mobile/README.md) и [`docs/16-mobile.md`](docs/16-mobile.md).

## G2 «Мир Завета» — мобильная версия стала игрой

G1 был проверкой боя на стекле. **G2 — уже открытый мир**: 5 зон 40×40 с порталами (безопасный город + 4 боевые), процедурная детализированная графика (тайлграунд, ~200 объектов на зону, 14 видов объектов, артикулированные спрайты, динамический свет, 4 погоды, туман, bloom, мини-карта), 6 классов канона, 11 типов мобов (включая учебные манекены) + 4 элиты + 4 мировых босса, лагеря с респавном, Волны Разлома, 60 уровней, дроп 6 редкостей с pity 40, аффиксы/сеты/руны/самоцветы, заточка +12, перековка, 18 талантов, 15 НПС с диалогами и сервисами, 9 глав пролога и 12 квестов единой цепочкой, репутация, чат и группа.

**Онлайн — настоящий.** [`server/server.js`](server/server.js) поднимает HTTP и WebSocket (RFC 6455) на чистом Node **без npm-зависимостей**: 30 Гц авторитетный тик, 20 Гц дельта-снапшоты, AOI, валидация скорости/коллизий, серверные кулдауны, `seq` против реплея, лут с владельцем, чат 4 каналов, группа, до 200 игроков. Клиент предсказывает своё движение и интерполирует удалённых игроков.

```bash
node server/server.js      # http://localhost:8080/ — телефон в той же Wi-Fi видит других игроков
```

GitHub Pages статичен, поэтому при отсутствии `wss://`-адреса игра честно показывает **«ОФЛАЙН-МИР · 4 союзника»**: ИИ-компаньоны с именами и классами сражаются рядом, но не выдаются за людей. Для постоянного онлайна — любой бесплатный Node-хост, готовы [`server/Dockerfile`](server/Dockerfile) и [`server/README.md`](server/README.md). Полная спецификация — [`docs/16-mobile.md`](docs/16-mobile.md) §16.13–16.22.

### G2.1–G2.3 — три волны исправлений приёмки

Выбор **всех 6 героев** (обработчик карточек + `?class=`), процедурный звук (`js/audio.js`: 24 SFX, арпеджио лута по редкости, амбиент 5 биомов), видимый лут с каждого моба с лучами редкости и подписями, инвентарь на 40 слотов с карточкой предмета и сравнением силы, рынок с общим серверным order book и комиссией 5% (sink), торговля 1:1 с атомарным обменом, шёпот, эмоции, ростер, приглашения в группу и тап по игроку прямо в мире. Графика получила фаски и микрорельеф тайлов, дым/искры костров, свечение кристаллов, анимированную воду, останки врагов, объёмные лучи и цветокоррекцию биома. Сервер теперь рассылает `syncInitial()` (кошелёк, общий рынок, ростер), хранит idem-ключи, ledger сделок и реестр владения предметами. G2.2 закрыл вторую волну: отдельная панель **«Снаряжение»** с 8 кликабельными слотами, «Надеть лучшее», «Снять» и сравнение прироста силы; фильтр лута по умолчанию `all`; **магнит лута** 9.5 тайла, дроп только в проходимых клетках, авторазбор weakest-common при сумке 40/40 и кнопка «Забрать лут» на HUD; анти-лаг — отсечение/лимит лута, кэш воды и мини-карты, троттлинг `sync_items`, HUD 5 Гц, адаптивное качество по FPS. G2.3 ответил на третью волну: старт теперь в **Пристани Завета** — безопасном городе с 7 НПС, домами, прилавками, фонарями и учебным двором, где не нападают и не гибнут. **АКТ I · ПРОЛОГ** из 9 глав ведёт от разговора с Эльдарой через знакомство с жителями, дорогу к двору, первое надевание вещи, манекены, лут, кузницу и прилавок к воротам Рощи. За каждую главу выдаётся ровно одна вещь: старт только с оружием, к 9-й главе собраны все 8 слотов, редкость растёт `common → rare → epic`. 12 квестов Завета открываются только после пролога; у входа в Рощу добавлена безопасная дозорная тропа. Подробности — `docs/16-mobile.md` §16.22–16.24.

## Ключевые решения

- **Движок:** Unreal Engine 5.6 (Nanite/Lumen на ПК, 4 профиля масштабируемости на мобильных), изометрическая камера с зумом и поворотом.
- **Сеть:** авторитетный сервер 30 Гц, QUIC + Protobuf, AOI 120 м, 4 000 CCU на реалм × 12 реалмов × 4 региона.
- **Бой:** 6 классов × 3 специализации, додж с i-frames, комбо, крит, 7 стихий и 7 реакций, питомцы и призывы, боссы с 4 фазами.
- **Экономика:** 92% предметов создаются игроками, двойная запись в ledger, контроллер инфляции, 4 зоны закона, BURN части лута.
- **Монетизация:** только косметика и боевой пропуск; Кристаллы Зари **не конвертируются и не передаются**; хартия из 10 обязательств проверяется линтером.
- **Масштаб:** 54 месяца, пик 252 FTE, $224.68M, глобальный запуск 2031-Q2, 5 сезонов в год.
- **Телефон вперёд:** G1 доставил срез боя, G2 — открытый мир, гринд, квесты и сетевой контур, G2.1 — 6 классов, звук, лут, инвентарь, рынок, торговлю 1:1 и социальные действия, G2.2 — рабочую экипировку, лут без потерь и плавность, G2.3 — безопасный город, сюжетный пролог и постепенную экипировку; контракты ввода, камеры и телеграфов зафиксированы до переноса на UE 5.6.

## Проверка целостности

`tools/verify_canon.py` проверяет 251 условие: 16 документов, веса дропа, таблицу заточки, 6/18/48/144 по классам, биомы, отсутствие конвертера DC→Silver в SQL, совпадение бюджета с каноном, сгенерированные артефакты, а также PWA-манифест, иконки, офлайн-кэш, привязку боя к канону и отсутствие внешних зависимостей в мобильном срезе. Используется как CI-гейт перед мержем в дизайн-библию.
