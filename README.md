# АРКЕОН: Пепел Завета / ARKEON: Ashes of the Covenant

> Изометрическая MMORPG-ARPG нового поколения для Android, iOS и ПК.
> *«Мир не погиб. Он перестал держать слово.»*

Этот репозиторий — **производственная дизайн-библия** проекта (Phase 0 / Discovery): 15 документов, machine-readable канон, исполняемые симуляторы, SQL-схема и интерактивный хаб. Документы написаны как реальный коммерческий продукт уровня Diablo Immortal / Lost Ark / Albion Online с расчётом на 10M+ MAU, без упрощений и без Pay-To-Win.

---

## Быстрый старт

```bash
# Интерактивный хаб дизайн-библии (навигация, слои карты, классы, графики, поиск)
python3 -m http.server 8000 --bind 0.0.0.0
# откройте http://localhost:8000/  (в Arena — живой preview на порту 8000)

# Пересборка всех моделей и артефактов (только stdlib Python 3.11+)
python3 tools/gen_docs.py          # таблицы классов в docs/05 + схема ролей
python3 tools/economy_sim.py       # 30 дней экономики + CSV + SVG
python3 tools/combat_model.py      # DPS/TTK 6 классов + CSV + SVG
python3 tools/financial_model.py   # бюджет $224.68M + сценарии + SVG
python3 tools/verify_canon.py --strict   # 83 проверки согласованности (CI-гейт)
```

## Ключевые решения

- **Движок:** Unreal Engine 5.6 (Nanite/Lumen на ПК, 4 профиля масштабируемости на мобильных), изометрическая камера с зумом и поворотом.
- **Сеть:** авторитетный сервер 30 Гц, QUIC + Protobuf, AOI 120 м, 4 000 CCU на реалм × 12 реалмов × 4 региона.
- **Бой:** 6 классов × 3 специализации, додж с i-frames, комбо, крит, 7 стихий и 7 реакций, питомцы и призывы, боссы с 4 фазами.
- **Экономика:** 92% предметов создаются игроками, двойная запись в ledger, контроллер инфляции, 4 зоны закона, BURN части лута.
- **Монетизация:** только косметика и боевой пропуск; Кристаллы Зари **не конвертируются и не передаются**; хартия из 10 обязательств проверяется линтером.
- **Масштаб:** 54 месяца, пик 252 FTE, $224.68M, глобальный запуск 2031-Q2, 5 сезонов в год.

## Проверка целостности

`tools/verify_canon.py` проверяет 83 условия: 15 документов, веса дропа, таблицу заточки, 6/18/48/144 по классам, биомы, отсутствие конвертера DC→Silver в SQL, совпадение бюджета с каноном и наличие всех сгенерированных артефактов. Используется как CI-гейт перед мержем в дизайн-библию.
