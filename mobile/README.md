# АРКЕОН · Мобильная версия · G1 «Рубеж»

Телефонный **вертикальный срез боя** проекта «АРКЕОН: Пепел Завета». Это не упрощённая версия игры и не замена клиенту на Unreal Engine 5: это первый исполняемый этап, на котором проверяется главный риск мобильного ARPG — **ощущаются ли вес удара и читаемость телеграфа на стекле телефона**.

Открывается в мобильном браузере, устанавливается как PWA, работает офлайн, не требует сборки, CDN, аккаунта и сервера.

---

## Как открыть на телефоне

**Вариант 1 — предпросмотр Arena (быстрее всего).** Возьмите выданный адрес живого предпросмотра и добавьте `/mobile/`:

```
https://<порт>-<идентификатор>.e2b.app/mobile/
```

**Вариант 2 — локально в той же сети Wi-Fi.** Из корня репозитория:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

На телефоне откройте `http://<IP-адрес-компьютера>:8000/mobile/`. Узнать адрес: `ip addr` (Linux) или `ipconfig` (Windows). Важен именно `http://`, а не `file://`: из файловой системы не работают service worker, manifest и загрузка канона.

**Установка на домашний экран.**
- Android / Chrome: меню → «Установить приложение» / «Добавить на главный экран».
- iOS / Safari: «Поделиться» → «На экран «Домой»». Иконка берётся из `icon-192.png` / `icon-512.png`; SVG-иконку iOS не поддерживает, поэтому растр генерируется скриптом.
- После первой успешной загрузки срез доступен без сети: `sw.js` кэширует оболочку, стили, логику и `../data/classes.json`.

## Управление

| Жест | Действие |
| --- | --- |
| Левый джойстик | Движение относительно камеры; чем дальше от центра, тем быстрее |
| Тап по навыку | Применение; долгое нажатие открывает Кодекс с описанием |
| Свайп по арене | Додж в направлении жеста: 0.30 с неуязвимости, 2 заряда, восстановление 5.5 с |
| Кнопка «Додж» | Додж назад от цели (для одной руки) |
| Два пальца | Pinch-зум 0.65–1.7 и поворот изометрии на 90° |
| Кнопка камеры | Поворот на 90° без жеста |
| «Искра» | Ультимейт при 100% заряда, накапливается от урона, реакций и окна BREAK |
| Пауза | Оверлей, Кодекс, настройки доступности |

С клавиатуры (при отладке на ПК): `WASD` — движение, `1`–`6` — навыки, `Q` — ультимейт, `Пробел` — додж, `Esc` — пауза.

## Что внутри среза

- **Изометрическая арена 36×36** с сеткой, границами, рунами и динамическим освещением; 30 Гц фиксированная симуляция, до 60 Гц рендер.
- **2 класса из 6 канонических**: Воин (Ярость, щит, комбо) и Маг (Мана, Астральные заряды, стихии). У каждого 6 навыков, додж и ультимейт; коэффициенты, стоимость, перезарядка и типы урона читаются из `../data/classes.json`. При недоступности канона включается встроенный `FALLBACK` с теми же значениями.
- **Страж Рубежа**: 3 600 000 HP (четверть канонического данж-босса 14 000 000), 4 фазы, шкала стойкости и окно BREAK, адды, 4 формы телеграфов (конус / круг / линия / кольцо), энрейдж на 90-й секунде.
- **7 стихийных реакций** из канона: Пар, Перегрузка, Стеклование, Взрыв, Очищение, Затемнение, Гармония.
- **Обратная связь**: цифры урона, частицы, искры, тряска экрана, вибрация, синтезированный WebAudio-звук (без аудиофайлов).
- **Экран «Мир помнит»**: итог боя, урон, DPS, реакции, точность доджей, время и «след в летописи» — отсылка к опоре P2.
- **Доступность**: уменьшение тряски, крупный текст, высокий контраст, отключение вибрации и мерцания, HUD не более 14% экрана, все цели не менее 44 dp, поддержка safe-area.

**Монетизация отсутствует полностью.** Ноль силовых SKU, никаких ускорителей, покупок валюты и рекламы: хартия P3 действует и в срезе. Косметика появится только на этапе G4 вместе с сервером.

## Проверки

```bash
node --check mobile/js/game.js
node tools/smoke_mobile.js
python3 tools/gen_mobile_icons.py
python3 tools/verify_canon.py --strict
```

`smoke_mobile.js` поднимает `game.js` в изолированном контексте Node с заглушками DOM/Canvas, ведёт полноценный бой за Воина до победы и бой за Мага до реакций, проверяет додж, ультимейт, источник данных (fallback и канон), отсутствие NaN и рендер на заглушке.
