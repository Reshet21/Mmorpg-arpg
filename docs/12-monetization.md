## 1. Дизайн-хартия «Никакой силы за деньги» (публичный документ)

| № | Обязательство | Как проверяется |
|---|---|---|
| 1 | За реальные деньги нельзя получить урон, HP, броню, скорость, КД, дроп, XP, Серебро, эфирит, рейтинг или доступ к контенту | `item_definitions.stat_power = 0` и `is_cosmetic = true` для всех purchasable SKU; линтер `tools/verify_canon.py` в CI |
| 2 | **Кристаллы Зари (DC) не конвертируются в Серебро, не передаются, не выводятся** | в схеме БД отсутствует таблица обмена; `premium_wallet` есть только в GLOBAL; ежеквартальный аудит |
| 3 | Боевые питомцы и призываемые существа — только игровая добыча; магазинные «спутники» — чисто визуальные объекты, без хитбокса и AI | проверка GAS-тегами в `09-client.md` §6 |
| 4 | Боевой пропуск не даёт силы, не ускоряет прогресс, не продаёт уровни | `battlepass_progress.claimed_tiers` содержит только `cosmetic_id` |
| 5 | Никаких лутбоксов с силой; любые рандомизированные косметические наборы публикуют вероятности и имеют pity | `drop_audit` + публичная страница odds |
| 6 | Никаких «энергетических стен», таймеров за пропуск, рекламы за бустер | ревью онбординга Community Manager |
| 7 | Цена cosmetics не зависит от прогресса/MMR/платежей игрока | A/B-тесты запрещены на цене; `billing_transactions.product_id` фиксирован |
| 8 | Все PvP-награды — косметика, титулы и жетоны, тратящиеся на косметику | `07-mechanics.md` §10 |
| 9 | Изменения баланса и дропа — только через PTR, патчноут за 14 дней, без компенсаций силой | `config_versions`, `11-roadmap.md` |
| 10 | При нарушении хартии: откат, публичный отчёт за 72 ч и бесплатный косметический набор всем активным аккаунтам | Owner: Executive Producer + Community Manager |

**Структурная гарантия (а не обещание):** даже если маркетинг захочет «продать меч +10», сделать это технически нельзя — у косметического Data Asset нет полей статов, у DC нет конвертера, у магазина нет доступа к `item_instances`.

## 4. Боевой пропуск: точная конструкция

| Параметр | Значение |
|---|---|
| Длительность | 10 недель = 1 сезон, 100 tier |
| XP за tier | 1 200 XP; гибкий недельный пул (накопление до 3 дней), ежедневные 3 задания + недельные 4 + сезонные 6 |
| Источники XP | любая активность: данж, рейд, арена, крафт, контракт, мировое событие, коллекции; **нет заданий «купи что-то»** |
| Бесплатный трек | 30% косметики, эмоции, 200 DC за сезон, титул «Возжённый» |
| Премиум-трек | остальная косметика, скин маунта, аура, украшение, 300 DC возврат; **+0 к статам** |
| Покупка уровней | **запрещена** |
| Пропуск дней | пул накапливается до 3 дней; после сезона не сгорает доступ к уже заработанным tier в течение 7 дней |
| Прозрачность | весь трек виден заранее, до покупки; «что я получу» — одним экраном |

## 5. Случайность и юридическое соответствие

| Юрисдикция | Требование | Решение ARKEON |
|---|---|---|
| Бельгия / Нидерланды | запрет платных лутбоксов | платных рандомизированных наборов нет вообще; косметика продаётся напрямую |
| Китай (разрешение на издание), Корея, Япония | раскрытие вероятностей, pity | публичная страница odds; pity на заработанные игровые ларцы; в Korea — локальный отчёт по закону |
| ESRB / PEGI / RARS | пометки «In-Game Purchases», возраст | 16+ / PEGI 12 / ESRB T, экран «Покупки в игре» при первом входе |
| GDPR / COPPA | согласия, лимиты на детей | age-gate, parental consent, лимит покупок для миноров, PII отдельно |
| Apple / Google / Steam | цены, возвраты, подписки | StoreKit 2 / Billing v7 / Steamworks, идемпотентные webhook'ы, возврат без потери уже выданной косметики |
| США (FTC) | честная реклама | в креативах не показывается сила/рейтинг за деньги, нет «U HAVE 24H» |

**Рандомизация** существует только для *заработанных в игре* ларцов: публичные веса 62 / 26 / 9.4 / 2.2 / 0.3 / 0.02% и pity Легендарной на 40-м (`06-economy.md`). Вероятности заточки `+0…+12` также публичны и неизменны без патчноута за 14 дней.

## 6. Юнит-экономика и сценарии

Из `tools/financial_model.py` (плато после глобального запуска, blended platform fee 27%, monthly OPEX $5.62M):

| Сценарий | MAU | DAU | ARPDAU | Платящие | ARPPU/мес | Gross/мес | Опер. прибыль/мес | Окупаемость $224.68M |
|---|---|---|---|---|---|---|---|---|
| Консервативный | 10M | 2.0M | $0.14 | 3.2% | $26.25 | $8.40M | $0.51M | 439 мес. (неприемлемо → триггер пересмотра UA/продукта) |
| **Базовый (план)** | **18M** | **3.6M** | **$0.17** | **4.2%** | **$24.29** | **$18.36M** | **$7.78M** | **28.9 мес. (~2.4 года)** |
| Агрессивный | 30M | 5.8M | $0.22 | 5.0% | $25.52 | $38.28M | $22.32M | 10.1 мес. |

**Воронка (базовый):** установка → D1 44% → D7 19% → D30 8.5% → в гильдии на D14 48% → первый платёж на D12 (медиана) → 4.2% MAU платят → ARPPU $24.29 → повторная покупка 62% в течение 60 дней. Ни один шаг воронки не использует «наказание за пропуск».

**Go/No-Go по монетизации:** консервативный сценарий объявляется «красным» — при ARPDAU < $0.15 на D90 включается план B: расширение косметического каталога и контент-сезонов, **но не** введение силовых SKU. Это зафиксировано в хартии и является главным отличием от типичной mobile-F2P-практики.

## 7. Магазин как UX-продукт

- В бою магазин не открывается; никаких попапов при смерти, при проигрыше, при получении плохого лута.
- Каждый SKU: предпросмотр на своём персонаже в реальном освещении, пометка «не влияет на силу», цена в локальной валюте, кнопка «вернуться к игре» в одном тапе.
- «Избранное» и «посмотреть в Кодексе» вместо countdown-таймеров и «осталось 2».
- История покупок и возвратов в профиле; возврат в течение 48 ч, если косметика не была экипирована (Store-политика).
- Никаких персональных цен, никаких A/B на цене, никаких «VIP-менеджеров» для китов.

## 8. Биллинг-архитектура (связь с `08`/`10`)

```
Store (Google/Apple/Steam/Epic) → signed webhook → Billing Service
  → idempotency_key (UNIQUE) → verify signature/receipt → global.billing_transactions
  → global.premium_wallet (atomic +amount_dc, revision++)
  → global.entitlements (cosmetic_id, source=purchase)
  → Kafka entitlement.granted → клиент обновляет гардероб
```
Повтор webhook'а не создаёт второй покупки; chargeback → `status='chargeback'`, косметика не отзывается у добросовестного игрока (анти-злоупотребление возвратами обрабатывается отдельно по risk-score). Ни один платёж не пишет в `realm.*` и не создаёт `item_instances` с `stat_power > 0`.

## 9. KPI монетизации и отчётность

| KPI | Таргет | Источник |
|---|---|---|
| Конверсия MAU → платящий | 4.2% | billing + accounts |
| ARPDAU / ARPPU | $0.17 / $24.29 | revenue_scenarios.csv |
| Доля выручки от BP | 13% | product_id |
| Доля выручки от топ-1% платящих | ≤ 22% | биллинг-аналитика (анти-китозависимость) |
| Возвраты / chargeback | < 1.2% / < 0.15% | сторы |
| Жалобы «P2W» в отзывах | < 0.5% | Community Manager, сентимент 14 языков |
| Нарушений хартии | **0** | квартальный внешний аудит + CI-линтер |

**Публичная отчётность:** ежеквартальный «Лист честности» — перечень всех SKU, подтверждение отсутствия силовых продаж, число нарушений и действий по ним, доля бесплатных игроков в топ-100 рейтинга (таргет ≥ 70%). Это прямое следствие опоры **P3 Равные правила для всех**.
