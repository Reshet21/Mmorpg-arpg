## 0. Одностраничное резюме (Executive Summary)

**ARKEON: Пепел Завета** — кроссплатформенная изометрическая MMORPG-ARPG на UE 5.6. Игрок — Возжённый, носитель Искры Завета в мире, где не перезажгли седьмой Светоч. Продукт соединяет три проверенных рынка: **бой** Diablo IV / Lost Ark (вес удара, телеграфы, уклонение, комбо), **социальную ткань** WoW (кланы, гильдии, рейды, общий мир, репутация) и **игровую экономику** Albion Online (игроки добывают, крафтят, торгуют, воюют за территории). Монетизация — исключительно косметика и боевой пропуск, закреплено публичной хартией.

| Параметр | Значение |
|---|---|
| Целевая аудитория | 10M+ MAU / 300K CCU на горизонте 24 мес. после глобального запуска |
| Ядро | 6 классов · 18 специализаций · 30 Гц авторитетный бой · 14 регионов · 8 данжей · 3 рейда · 6 мировых боссов · 8 PvP-режимов |
| Сессия | Мобильная 12–18 мин; ПК 45–90 мин; «одна цель за сессию» — обязательный UX-принцип |
| Прогрессия | L1→60 (~55 ч), Парагон 1→300, 5 сезонов/год по 10 недель |
| Экономика | 3 валюты + 2 токена, 7 тиров ресурсов, двойная бухгалтерия предметов, контроллер инфляции |
| Разработка | 54 месяца, пик 252 FTE, бюджет $224.68M (`12-budget.md`, `13-budget.md`) |
| Ключевой риск | Одновременно «AAA-графика» и «60 fps на среднем Android» → решается 4 профилями масштабируемости (`09-client.md`) |

## 1. Видение, опоры и анти-цели

Опоры **P1 Вес удара / P2 Мир, который помнит / P3 Равные правила** — см. `01-title.md`, §3. Любая фича проходит «ревью трёх вопросов»; отказ хотя бы по одному = возврат в дизайн.

### Явные не-цели (Non-goals) — защита скоупа

| Не делаем | Почему | Что делаем вместо |
|---|---|---|
| Авто-бой / авто-путь к квесту | Убивает P1, превращает ARPG в idle | «Одна цель за сессию», умный компас, быстрый тревел за Серебро |
| Pay-to-Win, ускорители, лутбоксы с силой | Нарушает P3, убивает экономику и рейтинг | Косметика, BP, эмоции, скины маунтов/спутников |
| Полный симулятор физики разрушений в сети | 200 мс budget не вывозит детерминированный Chaos | Серверно-авторитетные *состояния* разрушаемых объектов + предпечённые осколки |
| Общий нешардированый мир на 10 000 в одной зоне | Нельзя при 14 kbps/клиент | 4 000 CCU/реалм, слои города, 200v200 в отдельном battleground (`08-server.md`) |
| NFT / blockchain / вывод валюты | Юридические и репутационные риски, P3 | Внутриигровой рынок с серверным реестром владения |
| Хардкорный «всегда full-loot» | Отпугивает 80% мобильной аудитории | Градация Зелёная/Жёлтая/Красная/Чёрная зоны (`07`, §9) |
| Сюжет, обязательный для PvP | Раскалывает аудиторию | Кодекс и мировые голосования как опциональный слой |

## 2. Игрок и мотивации (психографика)

| Сегмент | Доля | Что ищет | Главная система | Метрика удержания |
|---|---|---|---|---|
| **Слаггер** (ARPG-фанат) | 28% | Отклик, билды, лут | Бой + древо талантов + заточка | D7, кол-во респеков, глубина билдов |
| **Строитель** (Albion-тип) | 22% | Рынок, крафт, риск | Экономика, красные зоны, контракты | DAU-торговцев, объём рынка, Gini |
| **Социальный** (WoW-тип) | 26% | Гильдия, рейд, чувство принадлежности | Гильдии, рейды 8/24, голосовой чат | % игроков в гильдии, рейд-посещаемость |
| **Соперник** (PvP) | 16% | Ранг, арена, осада | 8 режимов, MMR, осады | PvP-сессии/нед., отток после проигрыша |
| **Коллекционер** | 8% | Кодекс, титулы, косметика | Достижения, коллекции, BP | % завершённых коллекций |

**Дизайн-вывод:** каждый сегмент должен получать *свою* награду в *любой* активности. Поэтому даже соло-данж даёт: лут (слаггер), эфирит (строитель), репутацию фракции (социальный), жетоны доблести (соперник), страницу Кодекса (коллекционер).

**Возраст / рейтинг:** 16+, PEGI 12 / ESRB T. Никаких «тёмных» механик вовлечения: нет energy-стены, нет ежедневного «накажи себя за пропуск». Есть *гибкий* недельный пул наград (накопление до 3 дней), что критично для мобильной аудитории и совместимо с F2P.

## 3. Петли геймплея (Loop Architecture)

| Горизонт | Петля | Действие → Награда → След в мире |
|---|---|---|
| **3–8 с** | Микро-бой | Удар → ярость/фокус → финишер → телеграф врага → уклонение → окно урона → крит/реакция → лут-сигнал |
| **30–90 с** | Пак мобов | Выбор цели → комбо → AoE → подбор → авто-сортировка инвентаря → сравнение с надетым (1 тап) |
| **5–15 мин** | Событие / квест | Световая тропа → активность → босс/контракт → Серебро + эфирит + репутация → цена на рынке сдвинулась на 0.1% |
| **12–18 мин** | Мобильная сессия | «Одна цель» (данж / контракт / арена / крафт-заказ) → закрытие цели → экран «что изменилось» → отложенные награды |
| **45–90 мин** | ПК-сессия | Данж мифик+ / рейд-крыло / караван / осада → предмет + Пепельная печать + гильдейский налог |
| **День** | Ежедневный пул | 3 гибких задания, 1 мировой босс, 1 контракт, 1 проверка рынка → BP-опыт |
| **Неделя** | Гильдия / рейтинг | Осада territories, рейд-локаут, арена-ранг, аукционные позиции → перераспределение налогов |
| **10 недель** | Сезон | BP 100 tier, мировое голосование, новый модификатор, мягкий сброс рейтинга, **без вайпа предметов** |

**Обязательный UX-элемент:** в конце каждой сессии экран «Мир помнит» показывает 3 строки: «Вы зажгли/погасили…», «Цена эфирита T6 в Аш'Харе +2.1%», «Ваша гильдия удержала территорию №17». Реализация P2 в интерфейсе.

## 4. Камера, управление, читаемость

| Параметр | Значение | Комментарий |
|---|---|---|
| Проекция | Изометрическая, ортографическая с лёгким перспективным смешиванием (FOV 28°) | Без «рыбьего глаза»; сохраняет масштаб для прицеливания |
| Pitch | 48° по умолчанию, диапазон 35–62° | На мобильных два пальца = pitch |
| Zoom | 8–26 м (плавный, инерция 0.18 с), 5 фикс-пресетов | Авто-отъезд при 200v200 и при больших боссах |
| Поворот | 360°, свободный + snap каждые 45° на ПК, инерционный на тач | Никогда не ломает направление джойстика (пересчёт в camera-space) |
| Occlusion | Мягкое исчезновение препятствий (dither fade 0.25 с), силуэт игрока через стены | Обязательно для подземелий с 3 ярусами |
| Боевая камера | Lock-on (тап по врагу), soft aim, «камера угрозы» при телеграфе | Приоритет телеграфа над красотой: эффекты босса не перекрываются VFX игрока |
| Ввод: тач | Виртуальный джойстик с «плавающим центром», 6 слотов навыков + додж-свайп + ультимейт, цикл переключения целей | Хитбоксы навыков ≥ 44 dp; слоты настраиваются |
| Ввод: ПК | WASD + мышь, 1–6, Q/E, Space=dodge, R=ultimate, полный ремап | Равный функционал, не «порт мобильного интерфейса» |
| Ввод: геймпад | Поддержка, но **ранговый PvP сегрегирован по типу ввода** | Честность P3 |
| Доступность | Дальтонизм (3 профиля), reduce motion, крупный текст 130%, субтитры с направлением звука, one-hand mode, уменьшение тряски экрана, авто-подбор лута (настраивается), «медленные телеграфы» (+150 мс) | Соответствие WCAG 2.2 AA для UI; сертификация перед софт-ланчем |

## 5. Боевая система (спецификация верхнего уровня; подробно — `07-mechanics.md`)

**Авторитет:** сервер 30 Гц, клиент 60 Гц, снапшоты 20 Гц, буфер интерполяции 100 мс, клиентское предсказание движения + серверная реконсиляция, lag compensation ≤ 200 мс, окно очереди навыка 150 мс. Игрок видит свою атаку мгновенно (VFX + анимация), **урон применяет только сервер**.

**Формула урона** (`data/canon.json`):

```
D = Base × (1 + Σ additive) × Π multiplicative × (1 − DEF/(DEF + 1200 + 42·lvl))
    × (1 − resistance) × crit × (1 − DR) × (1 + vulnerability)
```

Слои аддитивов и множителей разделены намеренно: это защищает баланс от «сложившегося экспоненциально» билда и даёт Economy Designer предсказуемую кривую силы. Капы: крит 75%, CDR 45%, скорость атаки 2.5.

**Базовые тайминги:** додж 0.30 с i-frames + 0.15 с восстановления, 6.2 м, 2 заряда по 5.5 с; CC diminishing returns `1.0 → 0.65 → 0.40 → 0` со сбросом 18 с; бар стойкости босса; супер-армор у тяжелых классов; «Резонанс» стихий (7 реакций).

**PvP-шкала:** отдельная нормализация (урон ×0.08, HP ×2), что даёт TTK 9.5 с при том же билде, который в PvE выдаёт 42 000 DPS (`tools/combat_model.py`).

**Целевые TTK:** PvP 6–12 с, треш 3–6 с, элита 20–40 с, босс данжа 75–120 с, рейд-босс 300–360 с. L60 DPS-эталон: 42 000 DPS на манекене, 12 000 HP, 1 800 атаки, 2 400 брони.

**Читаемость боя в 200v200:** три уровня LOD сущностей (полная модель ≤ 40 м → упрощённая ≤ 80 м → «знамя/силуэт + имя» ≤ 120 м), агрегация урона в «суммарные цифры» вместо 400 всплывающих чисел, приоритет телеграфов AoE, динамическое снижение тикрайта до 20 Гц в баттлграунде (`08-server.md`, §7).

| Ось | Диапазон | Источник | Награда | Сток/ограничение |

| **Парагон** «Перезажигание» | 1–300 | Любой XP после L60 | Узлы Клятв, +0.4% к статам за ранг с убыванием | `XP_p=80 000+12 000·p`; кап 300, сезонного вайпа нет |
| Репутация | 0–9 × 5 фракций | Квесты, контракты, события | Рецепты, косметика, версии диалогов | Взаимоисключающие выборы на ранге 7 |
| Достижения | 480 на запуск | Все системы | Титулы, страницы Кодекса | Не дают боевой силы |
| Коллекции | 62 набора | Лут, тайные места, сезоны | Скины, эмоции, слоты гардероба | Только косметика/удобство |
| Титулы | 210 | Достижения, рейтинг, осады | Префикс/суффикс в чате | Проверяются сервером |
| PvP-ранг | 8 рангов | Арена, BG, осады | Косметика, жетоны доблести | Glicko-2, мягкий сброс по сезонам |

**Эндгейм-петля (L60):** выбор Клятвы недели → данж мифик+ / рейд / караван в Красной зоне → эфирит T8 → крафт или рынок → заточка/перековка → осада территории → налоговый доход гильдии → следующий цикл. Средняя неделя активного игрока: 6.5 ч; медиана предметной силы растёт ~18 IP/нед., что задаёт горизонт «не догнать донатом, но догнать игрой».

## 8. Предметы (сводка; подробно — `07-mechanics.md`, §6)

6 редкостей с бюджетом аффиксов 100 / 140 / 195 / 265 / 345 / 420. 12 слотов экипировки, 0–6 случайных аффиксов, сеты 2/4/6, до 3 гнезд под руны и самоцветы, заточка +0…+12, перековка одного аффикса (`500·1.35^r`, cap 25), улучшение тира через крафт. **Уникальные** предметы не имеют случайных свойств — у них фиксированный «заветный» эффект, меняющий ротацию, а не просто цифру.

Дроп-веса: 62% / 26% / 9.4% / 2.2% / 0.3% / 0.02%; «добор» (pity) на запечатанных ларцах, заработанных в игре, — гарант Легендарной на 40-м. Все лутбоксы — только за игровую активность, с публичными вероятностями; платных ящиков с силой нет (`12-monetization.md`).

## 9. Экономика (сводка; подробно — `06-economy.md`)

Игроки создают > 92% предметов в обращении. Серебро чеканится Конклавом из эфирита, **Кристаллы Зари не конвертируются в Серебро и не передаются** — это главный барьер против Pay-To-Win и RMT. Торговля: рынок с книгой ордеров (налог 1.5% выставление + 4.5% продажа), прямой трейд (2%), контракты с escrow, гильдейские лавки, 4 региональных рынка. Стоки: налоги, станции (4%), ремонт, заточка, перековка, тревел, налог территорий, «уничтожение» части лута в Красной/Чёрной зоне.

**Контроллер инфляции:** `R_t = clamp(0.75, 1.25, 1 + 0.6·(M_target − M_t)/M_target − 0.25·(PI_t − 100)/100)` — динамический множитель faucet-наград; цель sink/faucet = 1.08, индекс цен 100. Симуляция на 30 дней — `tools/economy_sim.py`, график `assets/charts/economy-30d.svg`.

**Антидюп:** каждый предмет — уникальный `item_uid` с историей владения в ledger двойной записи; единственный владелец; все мутации идемпотентны; клиент никогда не создаёт предметы (`10-db.md`, §5). **Антибот:** аттестация устройства + поведенческий risk-score 0–100 + экономические лимиты скорости + серверный RNG лута.

## 10. Мир и контент (сводка; карта — `04-world-map.md`)

14 регионов, ~96 км² суши + 34 км² моря, 3 яруса высоты в Хребте, 38 якорей быстрого перемещения, 7 тайных мест, 8 данжей (включая Башню Испытаний на 100 этажей), 3 рейда (8/16/24), 6 мировых боссов, 36 территорий гильдий, замок с осадой 200v200, морские маршруты с перехватом. Погода и время суток влияют на видимость, спавн ресурсов и отдельные механики (метель, шторм, песчаная буря, пепел).

**Плотность контента (таргет на регион):** 1 хаб, 4–6 POI, 1 данж, 2–3 мировых события / 45 мин, 12–18 элит, 3–5 точек сбора, 1 секрет, 1 «эхо-запись», 2 таблички с меняющимися ценами.

## 11. Социальные системы (сводка; `07-mechanics.md`, §8)

- **Чаты:** глобальный (шардированный, 1 сообщение / 8 с, антиспам), локальный (150 м), торговый, личный, групповой, рейдовый, гильдейский, альянсовый, системный. Модерация: классификатор + жалобы + аудит + апелляция (SLA 24 ч).
- **Голос:** WebRTC SFU, Opus 32 kbps/говорящий, push-to-talk, каналы группы/рейда/гильдии/ proximity 3D, добровольное согласие на запись для модерации, хеш-журнал, без раскрытия IP.
- **Связи:** друзья (200), список врагов/«Книга Вендетты» (только метка и законный баунти за Серебро, без грифинга), блок-лист, «последняя группа», кросс-реалм-приглашения.
- **Организации:** **клан** ≤ 12 (дружеский круг, общий Кодекс), **гильдия** ≤ 300 (9 рангов с битовой маской прав, склад, налоги, войны), **альянс** ≤ 3 гильдий (≤ 900 игроков, общий канал и осадный слот).
- **Группы:** 5 (данж), 8/16/24 (рейд), 200 (осада), с автопоиском ролей и LFG-доской.

## 13. UI/UX (спецификация для UI/UX Designer)

**Принцип «три тапа»:** любая цель сессии достижима не более чем за 3 действия из главного экрана. HUD-иерархия: (1) здоровье/ресурс/додж/ультимейт, (2) телеграфы и угрозы, (3) панель навыков, (4) цель и её бары, (5) миникарта/компас, (6) чат (сворачивается), (7) уведомления экономики.

| Экран | Ключевое решение |
|---|---|
| Главный HUD | Навыки 6 + додж + ультимейт; «сравнение предмета» одним тапом без открытия инвентаря |
| Инвентарь | 60 базовых слотов, авто-сортировка, фильтр «мусор → продать/разобрать», массовые операции с серверным preview |
| Карта | Слои: биомы / зоны закона / ресурсы / территории / события / маршруты; офлайн-кэш |
| Рынок | Книга ордеров, спред, история цен 30 дней, «крафтить или купить» калькулятор с учётом налога |
| Социальный | Единый «Круг»: друзья, клан, гильдия, альянс, LFG, голос в одном хабе |
| Кодекс | Достижения, коллекции, титулы, лор, мировые голосования, история операций с предметами |
| Магазин | Только косметика, обязательная пометка «не влияет на силу», предпросмотр на своём персонаже, цена в локальной валюте |
| Настройки | 4 графических профиля, доступность, ремап, приватность голоса, лимиты трафика, «лёгкий режим» для 2 ГБ ОЗУ |

**Мобильный бюджет UI:** ≤ 14% экранной площади под постоянный HUD в бою; все интерактивные элементы ≥ 44 dp; нижняя «безопасная» зона под жест; ни одного модального окна во время телеграфа босса.

## 14. Аудио, графика, производительность (сводка; `09-client.md`)

UE 5.6: Nanite + Lumen на ПК Ultra/High; на мобильных — запечённый GI + динамические зонды + упрощённые тени + VFX-LOD; 4 профиля (Ultra / High / Medium / Low). Цели: ПК 60–120 fps @1440p, флагманы 60 fps @1080p 30 мин без троттлинга > 3 °C, средние устройства 30 fps @720p, ОЗУ ≤ 3.2 ГБ, стартовый пакет ≤ 2.2 ГБ + докачка через CDN, дельта-патч ≤ 120 МБ/нед. Разрушаемость: 3 класса объектов, серверные state-биты, предпечённые фрагменты Chaos. VFX-приоритет: телеграф > реакция > урон > декор. Аудио: Wwise, 3D-позиционирование, адаптивная оркестровая партитура по состоянию Светочей, отдельный микс для телефона (динамический диапазон 12 дБ).

## 15. Живые операции, аналитика и KPI

**Сезонный ритм:** 10 недель = 1 сезон; неделя 0 — патч-ноут + PTR; недели 1/5 — контент-дропы; неделя 8 — осадный финал; неделя 10 — голосование + мягкий сброс рейтинга. Никаких вайпов предметов и Серебра.

| KPI | Таргет на глобальный запуск | Владелец | Источник |
|---|---|---|---|
| D1 / D7 / D30 | 44% / 19% / 8.5% | Lead Game Designer | ClickHouse, `15-launch.md` |
| Crash-free sessions | ≥ 99.6% | Mobile Architect | Crashlytics-совместимый pipeline |
| p95 входа в мир | < 8 с | Backend Architect | OpenTelemetry |
| p95 RTT в бою, EU | < 60 мс | Network Engineer | gateway-метрики |
| конверсия в платящего | 4.2% | Monetization Designer | billing-события |
| ARPDAU / ARPPU | $0.17 / $24.29 мес. (базовый сценарий) | Economy Designer | финансовый модель `tools/financial_model.py` |
| доля в гильдии на D14 | ≥ 48% | MMORPG Systems Designer | social-события |
| sink/faucet (7д скольз.) | 1.05–1.12 | Economy Designer | `tools/economy_sim.py` |
| доля предметов игроков на рынке | ≥ 92% | Economy Designer | ledger-отчёт |
| инциденты дюпа | 0 подтверждённых | Backend Architect | реконсиляция ledger |
| доля забаненных ботов от всех банов | < 35% (цель — аккуратность, не масса) | Anti-Cheat / DevOps | risk-score аудит |

**A/B-тесты** только на UX/монетизацию/онбординг, **никогда** на боевую формулу или дроп без публичного PTR и объявления за 14 дней (P3). Feature flags + kill switch для каждой системы; канареечные релизы 1% → 10% → 50% → 100% (`08-server.md`, §11).

## 16. Зависимости, риски и критерии готовности

| Риск | Вероятность | Ущерб | Митигация | Владелец |
|---|---|---|---|---|
| AAA-графика не тянет на среднем Android | Высокая | Высокий | 4 профиля, VFX-LOD, бюджет ОЗУ, device farm 220 устройств | Mobile Architect |
| Экономическая инфляция / RMT | Средняя | Критический | контроллер, ledger, неконвертируемость DC, anti-RMT триаж | Economy Designer |
| Дюп при кросс-шардном трансфере | Средняя | Критический | Saga + escrow + идемпотентность + ночная реконсиляция | Backend Architect |
| P2W-восприятие из-за «питомцев» в магазине | Средняя | Высокий | жёсткое разделение: боевые питомцы — только in-game, магазинные — косметические спутники | Monetization Designer |
| 200v200 деградирует сеть | Средняя | Высокий | отдельный battleground, 20 Гц, LOD-агрегация, лимит AOI | Network Engineer |
| Социальная токсичность / голос | Высокая | Средний | модерация, согласие, mute по умолчанию в глобале, апелляции | Community Manager |
| Скоуп 54 мес. срывается | Высокая | Высокий | вертикальный срез с go/no-go на M9, фича-фриз на M38, внешний QA | Executive Producer |

**Definition of Done для вертикального среза (M9)** — обязательный минимум, без которого проект не переходит в препродакшен:
1. Один регион (Зелёный Предел) + хаб, 2 класса, 1 данж, 1 мировой босс, 30 Гц бой, 60 fps на Pixel 7 / iPhone 13 и 120 fps на ПК.
2. Рынок с книгой ордеров и ledger двойной записи, 1 крафт-цепочка T2→T4, контроллер инфляции в симуляторе.
3. 200 ботов-клиентов в нагрузочном тесте на одном реалме, p95 RTT < 80 мс, 0 рассинхронов инвентаря.
4. Группа 5, чат, друзья, голос в группе, один PvP-режим 3х3.
5. Вертикальный срез монетизации: косметический скин, предпросмотр, покупка, 0 эффектов на статы.
6. Полный telemetry-конвейер и дашборд 12 KPI из §15.
