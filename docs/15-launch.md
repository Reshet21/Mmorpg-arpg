## 3. Go/No-Go: измеримые врата

| gate | Метрика | Порог | При провале |
|---|---|---|---|
| Техническое | crash-free sessions | ≥ 99.6% | перенос, нельзя «залить хотфикс в день 0» |
| Техническое | p95 входа в мир / RTT EU | < 8 с / < 60 мс | добавить реалмы, отложить волну UA |
| Сеть | 4 000 ботов/реалм, 200v200 | 0 рассинхронов | DR-репетиция, повтор теста |
| Экономика | PI, sink/faucet за 14 дней reals | 94–108 / 1.02–1.15 | ручной режим, объяснение, без вайпа |
| Антидюп | подтверждённых инцидентов | **0** | стоп запуска |
| Удержание (soft launch) | D1 / D7 / D30 | 44% / 19% / 8.5% | пересмотр онбординга, перенос |
| Монетизация | конверсия / ARPDAU / refunds | 4.2% / $0.17 / < 1.2% | план B без P2W |
| Социальность | доля в гильдии на D14 | ≥ 48% | LFG-доработка |
| Сторы | рейтинг софт-ланча | ≥ 4.3 | разбор отзывов, фикс топ-3 болей |
| Соответствие | 14 языков, рейтинги, GDPR/COPPA, odds | 100% | юридический стоп |
| Комьюнити | апелляции / модерация SLA | < 24 ч | добор смены |
| Хартия | внешний аудит | 0 нарушений | стоп запуска |

**Правило:** врата — не «чек-лист для галочки». Несоблюдение хотя бы одной переносит дату и объявляется публично; стоимость переноса заложена в контингенси 12%.

## 5. Комьюнити, креаторы и киберспорт

| Программа | Масштаб | Правила |
|---|---|---|
| Creator Program | 300 → 1 200 креаторов | косметический набор, ранний доступ, **обязательный disclosure**, без фиксированного сценария, запрет обещаний «купи силу» |

| Dev Diaries | 1 раз в 3 недели | только факты и цифры, без маркетинговых превосходных степеней |
| PTR | с T−10 | баланс-изменения за 14 дней, публичные патчноуты, сбор возражений |
| PvP-лига «Семь Клятв» | 5 сезонов/год | призовой фонд — косметика и титулы, **не** сила; трансляции с официального канала |

**Модерация:** `07-mechanics.md` §8, SFU-голос с согласием, классификатор 14 языков, публичная статистика банов и доля ложных срабатываний < 0.3%.

| Инцидент | Действие | Коммуникация |
|---|---|---|

| Review bombing | не удалять, отвечать по существу, фиксить топ-3 боли | Community Lead |
| Утечка данных | DPO, уведомление по GDPR 72 ч, ротация ключей | Legal + EP |

## 8. Первые 90 дней после запуска

| Период | Фокус | Метрика успеха |
|---|---|---|
| Д1–7 | стабильность, вход, первые 3 часа онбординга | crash-free ≥ 99.6%, D1 ≥ 44%, рейтинг ≥ 4.3 |
| Д8–30 | социальность, LFG, первый рейд, рынок | D7 ≥ 19%, в гильдии ≥ 48%, crafted ≥ 92% |
| Д31–60 | сезон I, мифик+, осады, баланс по PTR | D30 ≥ 8.5%, PI в коридоре, 0 P2W-жалоб > 0.5% |
| Д61–90 | первое мировое голосование, сезон II анонс | ≥ 60% аккаунтов с актом VII проголосовали, ARPDAU ≥ $0.17 |
| Постоянно | еженедельный «Лист сообщества» + «Лист экономики» + «Лист честности» | SLA 24 ч по апелляциям |

**Главный принцип запуска:** мы продаём не «ожидание», а работающий продукт. Любая метрика, которую нельзя показать публично, не используется в рекламе. Это продолжение опоры **P3 Равные правила для всех** и хартии `12-monetization.md`.

## 9. Критерии приёмки плана

- [ ] Все 12 Go/No-Go порогов измеримы и имеют владельца; невыполнение = перенос, а не «повезёт».
- [ ] Бюджет $41.51M разбит по каналам и годам и совпадает с `13-budget.md`.
- [ ] 14 языков, 4 региона софт-ланча, 3 CBT и PTR вписаны в T−18…T−0.
- [ ] Ни один креатив не обещает силу за деньги; disclosure и ASO проходят Legal.
- [ ] План кризисных коммуникаций покрывает 5 сценариев с SLA ≤ 60 мин / ≤ 72 ч.
